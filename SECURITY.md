# Security policy

## Supported versions

Only the latest release of WDF AI Metadata Remover gets security fixes. Please update to the current version from [WordPress.org](https://wordpress.org/plugins/wdf-ai-metadata-remover/) before reporting.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or the WordPress.org support forum.

Instead, email **support@webdesignerfactory.com** with the subject line "Security: WDF AI Metadata Remover" and include:

- the plugin version and your WordPress and PHP versions
- what the issue is and what an attacker could do with it
- steps to reproduce it, or a proof of concept

You can also use GitHub's private vulnerability reporting on this repository if it's enabled.

## What happens next

- We confirm we've received your report within 3 business days.
- We investigate and keep you updated on progress.
- Once a fix is ready, we release it on WordPress.org and credit you in the changelog if you'd like.

Please give us a reasonable amount of time to release a fix before you disclose the issue publicly.

Thanks for helping keep WordPress sites safe.
